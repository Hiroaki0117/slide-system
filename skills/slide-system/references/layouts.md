# Layout selection

Choose a layout from the slide's narrative job and primary material. Do not invent a new arrangement merely for visual variety.

| Layout | Primary use | Typical contents |
|---|---|---|
| `cover` | Opening | Eyebrow, title, optional subtitle, date |
| `agenda` | Useful navigation | Three to five meaningful sections |
| `section_divider` | Major transition | Section label and one short statement |
| `single_message` | One claim or question | One headline and limited support |
| `text_focus` | Explanation or cautions | Lead, short body or bullets, optional callout |
| `text_visual` | Meaningful image plus explanation | One dominant image and one text area |
| `comparison` | Two or three alternatives | Shared dimensions and balanced columns |
| `process` | Sequence or roadmap | Three to six ordered steps |
| `data_focus` | Key metrics or chart | One dominant metric group or chart and interpretation |
| `table` | Exact repeated fields | A small table with units and source |
| `exercise` | Learner action | Prompt, conditions, time if useful, completion state |
| `summary_action` | Conclusion and next step | Final synthesis and one to three actions |
| `sources_appendix` | Source traceability | Compact source records |

## Rules

- Keep title, main content, source, and page number in separate safe areas.
- Use equal outer margins by default; internal composition may be asymmetric.
- Do not use four or more columns.
- Do not fill empty space with decoration or unrelated images.
- Use the same layout consecutively when the repeated structure helps understanding.
- Do not switch layouts only to avoid repetition.
- For overflow, remove duplication, shorten copy, move secondary detail, split the slide, then change layout.
- Use a table for exact mappings; use a process only when sequence matters; use a diagram only when relationships are materially clearer than prose.

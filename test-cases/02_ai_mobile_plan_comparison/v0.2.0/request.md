PCを持たず、iPadとiPhoneだけで生成AIを使う初心者が、有料プランへ切り替える価値を判断できる資料を作成する。

成果物は次の3資料へ分ける。

1. ChatGPT Free・Plus詳細ガイド
2. Claude Free・Pro詳細ガイド
3. ChatGPTとClaudeの選び方ガイド

価格や単純な利用量だけでなく、完成物を作る機能、モデルの違い、調査機能、Projects、Skills・Plugins、iPad・iPhoneだけで使う場合の制約を重点的に扱う。

各社の最新公式情報を調査し、内容契約と構成案を利用者へ提示する。利用者が承認するまではHTML・PDFを生成しない。

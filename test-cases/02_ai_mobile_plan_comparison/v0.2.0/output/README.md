# AIモバイルプラン比較 v0.2.0

PCを持たず、iPad・iPhoneで利用する人を想定した3種類の資料です。

## 成果物

- `chatgpt-free-plus-mobile-guide.html` / `.pdf`
  - ChatGPT FreeとPlusの違い
  - Work、モデル選択、Effort、Projects、Pluginsを重点的に整理
- `claude-free-pro-mobile-guide.html` / `.pdf`
  - Claude FreeとProの違い
  - Research、Cowork、利用量、Projects、Skillsを重点的に整理
- `chatgpt-claude-mobile-choice-guide.html` / `.pdf`
  - ChatGPTとClaudeを、やりたい作業から選ぶための横断比較

HTMLは単体で開ける自己完結形式です。PDFは16:9で、HTMLと同じ内容を収録しています。

## 見方

最初に各サービス別の資料を読み、最後に横断比較を見る順番を推奨します。料金だけではなく、無料版で一度試し、どの工程で困ったかを有料化の判断材料にしてください。

## 情報の基準日

2026年8月12日。各資料の末尾に公式出典を記載しています。機能の提供状況、モデル名、利用上限はアカウントや時期で変わるため、契約前にアプリ内表示を確認してください。

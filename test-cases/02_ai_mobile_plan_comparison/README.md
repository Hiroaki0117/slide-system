# AI Mobile Plan Comparison

PCを持たず、iPadとiPhoneだけで生成AIを使う人向けに、ChatGPT Free・PlusとClaude Free・Proを比較するスライドです。

価格、利用枠、Project、ファイル、Claude Skillsなど変動しやすい情報は、2026年8月12日に各社公式サイトで確認しています。公式情報から導いた運用判断は、スライド上で「推論」または「運用提案」と明示します。

`output/v0.1.0/`と`split/*/output/v0.1.0/`は、価格・利用量中心になり、Work、モデル、Research、Cowork、Skills・Pluginsの比較が不足した失敗例として保存します。

v0.2.0では、修正済みハーネスの内容契約ゲートを使い、次の順に作り直します。

1. 公式情報を調査する
2. 3資料それぞれの必須論点と構成を内容契約にする
3. 利用者の承認を得る
4. 承認後にHTML・PDFを生成する
5. 内容QAと視覚QAを通す

依頼原文は`v0.2.0/request.md`、内容契約の下書きは`runs/run_20260812_002/brief/`に保存します。

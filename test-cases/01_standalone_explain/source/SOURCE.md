# チームの知識を、探せる形で残す

## この原稿について

この原稿は、スライド生成仕様を検証するために作成した固定のテスト資料です。記載している組織名、調査結果、数値は、すべて架空の検証用サンプルです。実在する企業や調査結果として扱ってはいけません。

スライドで本原稿の数値を使用する場合は、短い出典を「検証用サンプル [S1]」とし、出典ページに次の情報を記載してください。

```text
[S1] Slide System Test Case 01「チームの知識を、探せる形で残す」検証用サンプル、2026-08-04
```

本原稿以外の外部情報を追加する必要はありません。外部情報を追加する場合は、検証可能な出典を別に記録してください。

## 背景

チームでは、担当者だけが知っている手順や判断のコツが増えやすくなります。チャットで質問すれば答えは得られても、数週間後には同じ質問が繰り返されます。共有フォルダーへ資料を置いても、ファイル名や保存場所が統一されていなければ、必要な人が見つけられません。

この状態を「メンバーの共有意識が低い」と考えると、投稿を呼びかける施策に偏ります。しかし、呼びかけだけでは忙しい時期に止まります。知識共有を続けるには、個人の意欲ではなく、短時間で残せて、後から整えられ、実際に使われる仕組みが必要です。

## 続かない3つの原因

### 1. 書く負担が大きい

最初から完成したマニュアルを求めると、投稿の心理的な負担が高くなります。文章の体裁を整える時間が取れず、知識が担当者のメモや頭の中に残ります。

### 2. 保存場所と名前が揃っていない

共有先が複数あり、分類方法も人によって異なると、投稿しても検索できません。「以前見たはずだが見つからない」という状態が続くと、メンバーは再び人へ質問します。

### 3. 使われた反応が返らない

投稿した知識が誰かの役に立ったか分からなければ、投稿者は効果を感じられません。利用者からの追記や改善も集まらず、古い情報がそのまま残ります。

## 続けるための3段階

知識共有は「残す・整える・使う」の3段階で設計します。この3つは一方向の作業ではなく、使った結果を次の記録と整理へ戻す循環です。

### 残す

日々の業務で得た気づきを、5分以内で記録します。完成した文書ではなく、次の担当者が迷わないための最低限の情報を残します。

記録項目は、原則として次の4つです。

- どんな場面で使う知識か
- 何をすればよいか
- どこで迷いやすいか
- 詳細を確認できる元資料は何か

### 整える

週に1回、15分だけ整理します。担当者は内容を書き直すのではなく、タイトル、分類、重複、更新日の確認に集中します。複数の投稿が同じテーマを扱っている場合は、代表となるページから関連情報へ移動できるようにします。

### 使う

質問へ回答するときは、口頭やチャットだけで終わらせず、該当ページへのリンクも返します。ページが不足していれば、利用者が追記します。使われた回数や改善された箇所を共有し、投稿が役立ったことを見えるようにします。

## 4週間の検証用データ

架空のチームAが、上記の運用を4週間試したという想定のサンプルデータです。導入前の直近4週間と、導入後の4週間を比較しています。

| 指標 | 導入前の4週間 | 導入後の4週間 |
|---|---:|---:|
| 知識の新規投稿数 | 12件 | 38件 |
| 検索で自己解決できた質問の割合 | 44% | 71% |
| 新任メンバーが基本業務を一人で行えるまでの日数 | 10日 | 7日 |
| 週次整理にかかった時間 | 実施なし | 週15分 |

この結果では、投稿数と自己解決率が増え、基本業務を一人で行えるまでの日数が短くなっています。ただし、これは効果検証を目的とした実在データではありません。また、4週間の前後比較だけでは、変化が運用によって起きたと断定できません。スライドでは、変化と因果関係を混同しないでください。

## 小さく始める方法

最初から全社共通の分類や完全なマニュアルを作る必要はありません。まず1つのチーム、1つの業務領域、4週間に限定して試します。

開始時に決めるのは次の5項目です。

1. 記録する場所を1つにする
2. 投稿項目を4つに絞る
3. 5分以内で投稿する
4. 毎週15分の整理担当を決める
5. 質問への回答時にページを使う

4週間後には、投稿数だけでなく、検索で解決できた質問、更新されたページ、繰り返し発生した質問を確認します。数字が増えなかった場合も、個人を責めず、記録項目、検索方法、整理頻度のどこに摩擦があるかを見直します。

## まとめ

知識共有を続ける鍵は、立派な文書を増やすことではありません。短時間で残し、後から整え、実際の質問や業務で使う循環を作ることです。

最初の一歩は、次に同じ質問を受けたときに再利用できる情報を、5分で1件残すことです。小さな記録が使われ、改善される経験を積むことで、知識共有を日常の仕事へ組み込めます。

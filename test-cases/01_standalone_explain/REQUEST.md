# Test Request 01: Standalone Explain

## 目的

最小限の依頼から、既定のコンテンツモード、資料タイプ、テーマ、出力プロファイルが選ばれ、制作前確認、生成、検査、修正まで進むことを確認します。

## 実行条件

- Claudeプロジェクト: 全仕様書を登録した検証用プロジェクト
- チャット: このテスト専用の新しいチャット
- 添付ファイル: `source/SOURCE.md`のみ
- 追加の画像、テンプレート、ブランド資料: なし
- 依頼文の変更: なし

## 送信する依頼文

次の本文だけを送信します。

```text
添付した原稿をもとに、社内の新任チームリーダー向けのスライドを作ってください。
業務改善の勉強会後に配布し、資料だけでも内容を理解できるようにしたいです。
```

## 制作前確認への回答

Claudeが制作条件を一括提示したら、内容に明らかな誤りがない限り、次の回答だけを送信します。

```text
この内容で進めてください。
```

提案された条件に誤りがある場合は修正せず、誤った提案内容を`RESULT.md`へ記録してテストを終了します。これは、追加指示によって既定値の選択ミスを隠さないためです。

## 保存するもの

- 制作前に提示された条件
- Claudeのゲート0に関する報告または行動
- 生成されたHTML
- HTMLから生成されたPDF
- Claudeが報告したQA結果
- 修正と再検査が行われた場合、その内容

生成物は`output/`へ保存します。ファイル名はClaudeが生成した名前を維持します。

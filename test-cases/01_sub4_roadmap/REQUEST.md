# Test Request 01: Sub-4 Roadmap

## このテストの狙い

AIに詳しくない人が、短い依頼文と手元のメモだけでスライドを依頼した場合を再現します。依頼を良く見せるための補足や、AI向けの構造化は行いません。

## 実行条件

- 全仕様書を登録したClaudeプロジェクトを使う
- このテスト専用の新しいチャットを開始する
- Claudeへ添付するのは`source/RUNNING_NOTES.md`だけ
- `EXPECTED.md`と`RESULT.md`は添付しない
- 画像、テンプレート、追加資料は添付しない

## 送信する依頼文

次の2文だけを、そのまま送信します。

```text
11/1の下関海峡マラソンでサブ4を目指したいです。
今の状況を添付したので、達成までのロードマップをスライドにしてください。
```

## テスト中の応答

- Claudeが現在の痛みなど安全上重要な点を質問した場合は、実際の状況を自然な言葉で答える
- Claudeが制作条件をまとめて確認した場合は、明らかな誤りがなければ「その内容でお願いします」と答える
- `standalone`、`how_to`、`warm_clean`、`html_pdf`などの内部名称は利用者側から伝えない
- 大会名の表記、開催年、残り期間を利用者側で先に訂正・補足しない
- 最初の成果物が出るまで、枚数、構成、色、図解、レイアウトなどを追加指定しない

## 保存するもの

- 最初に送った依頼文
- Claudeの最初の応答
- 確認質問と、それに対する回答
- 制作前に提示された条件
- 最初に生成されたHTMLとPDF
- Claudeが報告したQA結果
- 修正と再検証を行った場合は、その内容

成果物は`output/`へ保存します。初回出力は上書きせず、修正後の成果物と区別できる名前にします。

# Skill Test 01: Sub-4 Roadmap

## 目的

プロジェクトへ複数の仕様書を登録する方式と、カスタムスキルだけを登録する方式を、同じ素人レベルの入力で比較します。

## 事前準備

1. 別アカウントの無料版Claudeへ`dist/slide-system-skill-v0.1.2.zip`を登録する
2. コード実行とファイル作成を有効にする
3. このテスト専用の新しいチャットを開き、`slide-system`スキルを有効にする

プロジェクトは作成せず、`00_MASTER.md`などの仕様書、`EXPECTED.md`、`RESULT.md`、画像、テンプレートは添付しません。

## 入力

添付するのは`source/RUNNING_NOTES.md`だけです。次の2文を変更せず送ります。

```text
11/1の下関海峡マラソンでサブ4を目指したいです。
今の状況を添付したので、達成までのロードマップをスライドにしてください。
```

## テスト中の対応

- 安全上重要な質問には、実際の状況を自然な言葉で答える
- 安全上重要な質問へ答えた直後に制作が始まらず、制作条件の提示で再度停止することを確認する
- 制作条件のまとめが正しければ「その内容でお願いします」と答える
- 枚数、構成、色、レイアウト、出力形式を利用者側から補足しない
- 通常の進捗が止まった場合は「続けてください」とだけ送る
- 制限到達時は、その時点でダウンロードできるファイルとClaudeの最後の応答を保存する

## 合格の最低条件

- 最終的なHTMLとPDFをダウンロードできる
- PDFの全ページに内容があり、欠落、重なり、切れがない
- 途中のコード、ページごとの確認実況、長いQAログが大量に表示されない
- 制限をまたいだ場合も、作り直しではなく保存済みの下書きから再開できる

結果は`RESULT.md`へ追記し、生成物は`output/v0.1.2/`へ保存します。過去バージョンは比較用に残します。

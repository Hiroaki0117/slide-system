# Results

実行時に次のフォルダを作り、環境ごとの成果物を混ぜずに保存します。

```text
chatgpt-free/
chatgpt-plus/
claude-free/
claude-pro/
```

各フォルダの標準ファイル名は次のとおりです。

```text
RESULT.md
conversation.md
deck.html
deck.pdf
qa-report.json
screenshots/
```

`RESULT.md`は同じ階層にある`RESULT_TEMPLATE.md`をコピーして記録します。取得できなかった成果物は空ファイルを作らず、`RESULT.md`へ理由と到達地点を記載します。

# Design Pack Template

新しいテーマは`warm_clean`を直接変更せず、この契約に沿って追加します。

必須ファイル：

```text
design.json
tokens/colors.json
tokens/typography.json
tokens/spacing.json
tokens/shapes.json
layouts/layouts.json
components/components.json
qa/rules.json
```

題材固有の文章、数値、ページ構成はデザインパックへ入れません。共通の最小文字サイズ、安全余白、はみ出し禁止、出典可読性を弱めることもできません。
